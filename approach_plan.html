Vast Multi-Strategy Chunking (MSMARCO-XI)

Semantic Distance Splitting

Instead of rigid 500-token blocks, documents are split dynamically using embedding changes across sliding paragraphs. Boundaries are created when similarity drops below the statistical standard deviation ($S < \mu - \sigma$).

Parent-Child Hierarchy

Child passages are chunked small (128 tokens) with overlap to hold dense semantic targets. Upon vector matching, the system resolves its mapped parent block (512 tokens) containing full context, eliminating context cutoff errors.

Metadata-Aware Indexing

Metadata nodes index source language code, document ID references, and language namespace tags. Vector queries query matching language namespaces directly, eliminating cross-lingual noise indices.
